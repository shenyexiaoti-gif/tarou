## 1. 現在の外部評価の構造

外部評価は「リンクの本数」から「**エンティティとしての評価**」へ移っている。

評価されているもの:
- 良質なサイトからの**文脈のある**リンク
- **リンクを伴わないブランド言及**（Googleの特許では「implied link（暗黙のリンク）」として扱われる概念がある）
- 指名検索の量（ブランド名で検索される回数）
- 業界文脈での共起（自社名が業界の重要語と一緒に語られる頻度と文脈）
- 第三者による評価・レビュー・受賞・取材

**重要:** これはAI検索でも同じ構造で効く。AIは「誰が信頼できる情報源か」を、Web上の言及の分布から推定している（→ `06-ai-search-geo.md`）。

## 2. 被リンクの質の見方

| 見る点 | 良い | 悪い |
|---|---|---|
| 関連性 | 同業・関連テーマの文脈 | 無関係なジャンル |
| 配置 | 本文中、文脈に沿った位置 | フッター・サイドバー・一括リンク集 |
| アンカーテキスト | 自然（ブランド名、URL、文脈語）の分散 | 商用KWの完全一致が不自然に集中 |
| 発信元 | 実在の運営者、独自コンテンツ、実トラフィック | リンク販売サイト、コピーサイト、PBN |
| 属性 | 編集判断による自然なリンク | 対価を伴い `rel="sponsored"` 無し |

**リンク属性の使い分け（張る側の責任）**
- `rel="sponsored"`：広告・スポンサード・アフィリエイト
- `rel="ugc"`：ユーザー投稿（コメント、フォーラム）
- `rel="nofollow"`：保証しないリンク全般
- 通常の推薦リンクは属性なし（follow）

**本数より分布。** 100本の同種リンクより、10種の異なる文脈からの10本のほうが強い。

## 3. 安全に被リンクを獲得する手法

1. **リンクされる資産を作る**：独自調査データ、業界統計、無料ツール、テンプレート、用語集、比較表。**引用したくなる形（グラフ・数値・出典表記例）で提供する**
2. **一次情報の公開**：自社データの年次レポートは最も引用されやすい
3. **専門家として登場する**：取材対応、寄稿、登壇、ポッドキャスト、業界メディアのコメント
4. **既存の言及を回収する**：ブランド名で言及されているがリンクが無いページに、丁寧に依頼する（費用対効果が最も高い施策の一つ）
5. **リンク切れの置き換え提案**：関連テーマで404になっているリンク先の代替として自社コンテンツを提案
6. **共同企画**：業界団体、パートナー企業、大学・研究機関との共同調査
7. **地域・業界のディレクトリ**：実体のある、審査のあるものに限る

## 4. デジタルPR

被リンク獲得を目的にしたPR。成立条件は「**ニュース性**」。

- ネタの型：独自調査の意外な結果／時事との接続／地域データ／ランキング／実験
- 配信先は数を撒くより、**そのテーマを実際に扱っている記者・メディアに個別に**
- プレスリリース配信サービスのリンクはSEO効果が限定的（多くがnofollow / 転載重複）。**PRの目的は認知と二次取材であって、リンクは副産物**と考える
- 成果指標：掲載数、掲載メディアの質、リンク獲得数、指名検索の増加、AI検索での引用（→ `07-measurement.md`）

## 5. 未リンクの言及（サイテーション）とエンティティ

**エンティティを確立する作業リスト**
- 表記の統一（社名・サービス名・住所・電話番号を全チャネルで完全一致）
- 公式プロフィールの整備：会社サイトの会社概要、SNSプロフィール、業界データベース、採用媒体
- `Organization` 構造化データの `sameAs` で公式プロフィールを列挙（→ `04-structured-data.md`）
- 代表者・執筆者個人のプロフィールも同様に整備（Person エンティティ）
- Wikipedia／Wikidataは条件を満たす場合のみ（**自作自演の記事作成はしない。規約違反かつ逆効果**）
- 言及モニタリング：ブランド名・サービス名・代表者名のアラートを設定し、言及を検知したら対応する

## 6. 危険な手法（やらない）

- リンクの売買、リンクを目的とした金銭・物品の提供（`rel="sponsored"` 無し）
- 相互リンク集、過剰な相互リンク
- 自作自演のブログネットワーク（PBN）
- 他人の権威あるドメインの一部を借りて自社商用コンテンツを載せる（**サイトの評判の不正使用／パラサイトSEO**：明確な違反）
- 期限切れドメインの購入と無関係コンテンツでの再利用（**期限切れドメインの不正使用**）
- 自動投稿によるコメントスパム、フォーラムスパム
- 無関係なディレクトリへの大量登録

いずれも手動対策またはアルゴリズムによる評価無効化の対象（→ `08-spam-penalty.md`）。

## 7. ローカルSEO

**Googleビジネスプロフィール（GBP）を整備する**
- カテゴリ設定（主カテゴリは最重要。1つに絞る）
- NAP（名称・住所・電話）を公式サイトと完全一致させる
- 営業時間、祝日対応、サービス内容、属性、写真（定期的に追加）
- 投稿機能を使って更新を継続
- **口コミ**：獲得の仕組みを作る（依頼のタイミングと導線）。全件に返信する。**報酬による口コミ誘導・自作自演は禁止**
- Q&Aに自社で想定質問を用意しておく

**ローカルの評価軸**：関連性（Relevance）／距離（Distance）／知名度（Prominence）。距離は操作できないので、関連性と知名度に投資する。

**サイト側**：`LocalBusiness` 構造化データ、地域ページ（実体のある内容。同文の地名差し替え量産は doorway pages に該当し違反）、地域メディア・地域団体からの言及。

## 8. 日本市場特有の論点

- **Googleが支配的**。Yahoo! JAPANはGoogleの検索技術を利用しており、対策は基本的に共通（表示面のUIは異なる）
- **Bing** はWindows/Edge環境で一定シェア。加えて**AI検索の一部の基盤**でもあるため、Bing Webmaster Toolsへの登録とインデックス確認は低コストでやっておく
- **検索行動の分散**：若年層はSNS（Instagram / TikTok / X / YouTube）とAIチャットで探す。BtoCは検索エンジン外の入口を併走させる
- **BtoBでは指名検索と業界メディアが効く**。展示会・業界紙・士業や業界団体のサイトからの言及は日本市場で価値が高い
- **法規制**：景品表示法（優良誤認・有利誤認、ステルスマーケティング規制）、薬機法（健康・美容表現）、医療広告ガイドライン。**SEOのために誇大表現を書かせない**。ステマ規制により、対価を受けた記事は「広告」「PR」の明示が必要
- 数値・シェアは変動が速い。断定前に最新を確認する
