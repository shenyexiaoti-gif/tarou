## ❷ 明日の仕事で使える実務例A・B・C

31個に入る前に、仕事でそのまま使える形を3つ置いておきます。

実務例A（No.10・No.16）会議や説明会の冒頭に流す10秒動画

場面は、資料の表紙をただ映すだけの会議の始まりです。

表紙の画像を渡して、次のように頼みます。

```
この画像を最初のフレームとして使ってください。
10秒の横長の動画にしてください。
0〜3秒：画像全体をゆっくり映す
3〜8秒：中央のタイトルにゆっくり寄る
8〜10秒：そのまま止める
音は、落ち着いたピアノを小さめに。
画像の文字と色は変えないでください。
```

返ってくるのは、約10秒の音付き動画です。

人が確認するのは、タイトルの文字が崩れていないかです。

画像から動画にすると、途中で絵が描き直されるという報告があります（No.29）。

実務例B（No.13）週報や告知に添える短いGIF

場面は、文字だけの週報や社内告知に目を止めてもらいたい時です。

```
「今週の締め切りは金曜です」という文字が、
ゆっくり浮かび上がる短い動画を作ってください。
背景は白、文字は紺色にしてください。
できたら、メールや社内チャットに貼れるGIFにしてください。
```

返ってくるのは、動画と、それを変換したGIFです。

人が確認するのは、文字の誤字と、GIFにした後の画質です。

実務例C（No.09・No.24）商品写真から紹介用の縦動画

職種によっては、こちらが一番使う場面になります。

たとえば、手元にある商品の写真を1枚だけ使う場合です。

```
この商品写真を最初のフレームとして使ってください。
スマホ向けの縦長で、10秒の動画にしてください。
商品にゆっくり寄るだけで、商品の形と色は変えないでください。
背景の光だけ、やわらかく動かしてください。
```

返ってくるのは、商品に寄っていく縦長の動画です。

人が確認するのは、商品のロゴや形が元の写真と同じかどうかです。
