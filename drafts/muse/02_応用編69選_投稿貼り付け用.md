## ❷ 明日の仕事で使える実務例A・B・C

実務例A（No.32〜No.35）社内向けの解説動画

場面は、毎回同じ説明を口でくり返している手順や仕組みの説明です。

```
「新しい経費精算の手順」を説明する1分の動画を作ってください。
先に台本を作って、私に確認させてください。
台本が決まったら、スライドとナレーションを組み合わせてください。
```

実務例B（No.56）告知動画の読み間違いを止める

```
ナレーションで次の言葉は、かっこ内の読み方で読んでください。
定例会（ていれいかい）
新商品名（しんしょうひんめい）
読み方が分からない言葉は、作る前に私に確認してください。
```

返ってくるのは、読み方を指定したナレーション付きの動画です。

人が確認するのは、指定した言葉を、最後まで聞いて確かめることです。

実務例C（No.48・No.50）同じキャラクターで続ける

職種によっては、店や商品の顔になるキャラクターを毎週出したい場面があります。

```
この画像のキャラクターを、毎回同じ見た目で使います。
この画像を最初のフレームとして使ってください。
顔、髪型、服装、色は変えないでください。
動きは「右手を振る」だけにしてください。
```

返ってくるのは、同じ見た目のキャラクターが手を振る動画です。

人が確認するのは、前回の動画と並べた時に顔が同じかどうかです。
